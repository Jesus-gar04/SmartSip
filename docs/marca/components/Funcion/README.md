# Funcion

Una función del termo: ícono de línea de 2 px dentro de un círculo con trazo `trazo`, y su nombre en estilo `funcion`. Sobre agua, todo en blanco; sobre papel, todo en `tinta`.

Los cuatro íconos base son el termómetro, las barras, la campana y el pin. Los nombres usan verbos cotidianos y como máximo cinco palabras.
