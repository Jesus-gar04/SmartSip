# Boton

Botones en Bricolage Grotesque negrita, con esquinas `radius-md`. Una sola acción principal por pantalla.

- Sobre `papel`: principal en `azul` con texto blanco; secundario con contorno de `tinta`.
- Sobre agua (`azul`): principal en blanco con texto `azul-hondo`; secundario con contorno blanco.
- El texto es un verbo y lo que pasa: "Registrar sorbo", nunca "Aceptar".
