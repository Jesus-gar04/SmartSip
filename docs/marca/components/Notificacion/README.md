# Notificacion

El recordatorio de SmartSip, tal como aparece en el flyer: tarjeta `superficie` con esquinas `radius-lg`, ícono cuadrado de `tinta` con la `gota` viva, título de una línea y una frase de ayuda.

- Título: un hecho, no una orden ("Llevas 2 horas sin tomar agua").
- Ayuda: una salida fácil ("Un sorbo ahora y llegas a tu meta.").
- Solo llega al celular; el termo no vibra ni suena.
- Máximo una cada 90 minutos y nunca en el horario de silencio.
