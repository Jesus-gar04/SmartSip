# Logo

El logotipo de SmartSip, el mismo que va grabado en el termo: la gota de una sola línea que se enrosca en una S, sobre la palabra SmartSip. Siempre en un solo color: `tinta` (#241D18) sobre papel y blanco sobre `azul`. Los SVG son una reconstrucción a partir de la foto del termo; si aparece el archivo original, lo reemplaza.
